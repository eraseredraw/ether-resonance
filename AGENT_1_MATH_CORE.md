## 📐 МАТЕМАТИЧЕСКОЕ ЯДРО (ДЕТАЛИ)

### 1. Базовая формула `calcOriginal(x, y, time, scale)`

```javascript
function calcOriginal(x, y, time, scale) {
    // Уравнение 1: k = x / P.k - 12.5
    let k = x / P.k - 12.5;
    
    // Уравнение 2: e = cos(k) + sin(y / P.e) + cos(k / 2)
    let e = Math.cos(k) + Math.sin(y / P.e) + Math.cos(k / 2);
    
    // Уравнение 3: d = |e|
    let d = Math.abs(e);
    
    // Уравнение 4: q = x / 4 + P.q + d·k·(1 + cos(4d - 2t + y / 72))
    let q = x / 4 + P.q + d * k * (1 + Math.cos(4 * d - 2 * time + y / 72));
    
    // Уравнение 5: c = y·e / 594 - t / 8 + d / 6
    let c = y * e / 594 - time / 8 + d / 6;
    
    // Уравнение 6: X = q·cos(c) + 200
    let X = (q * Math.cos(c) + 200) * scale;
    
    // Уравнение 7: Y = (q/2 + 99·cos(c/2))·sin(c) + 6e + 200
    let Y = ((q / 2 + 99 * Math.cos(c / 2)) * Math.sin(c) + 6 * e + 200) * scale;
    
    return { X, Y };
}
```

### 2. Параметры формул `P = {k, e, q}`

| Параметр | Переменная | Диапазон | По умолчанию | Влияние на формулу |
|----------|------------|----------|--------------|-------------------|
| **K** | `P.k` | 2–20 | 8 | Делитель в уравнении 1. Меньше K = чаще волны |
| **E** | `P.e` | 5–50 | 24 | Делитель в уравнении 2. Меньше E = больше амплитуда |
| **Q** | `P.q` | 20–200 | 90 | Добавка в уравнении 4. Больше Q = больше размер |

### 3. Проблема нелинейности ползунков

**ПРОБЛЕМА:**
```
Ползунок 0→50:   огромные изменения формы
Ползунок 50→100: почти нет изменений
```

**ПРИЧИНА:** Параметры входят в формулы нелинейно (в знаменатель, под тригонометрию).

**РЕШЕНИЕ (реализовать в setup() при чтении слайдеров):**

```javascript
// Для P.k (экспоненциальная шкала)
const kSlider = document.getElementById('pk');
const kValue = parseFloat(kSlider.value);
P.k = Math.pow(kValue / 100, 0.7) * (20 - 2) + 2;

// Для P.e (экспоненциальная шкала)
const eSlider = document.getElementById('pe');
const eValue = parseFloat(eSlider.value);
P.e = Math.pow(eValue / 100, 0.75) * (50 - 5) + 5;

// Для P.q (линейная, но с точностью)
const qSlider = document.getElementById('pq');
P.q = parseFloat(qSlider.value);
```

**ОТОБРАЖЕНИЕ В UI:**
```javascript
// Обновлять отображаемое значение с точностью до 1 знака
document.getElementById('fk').textContent = P.k.toFixed(1);
document.getElementById('fe').textContent = P.e.toFixed(1);
document.getElementById('fq').textContent = P.q.toFixed(1);
```

## 🕸️ СЕТКА КООРДИНАТ

### Генерация точек

```javascript
const GX = 100, GY = 70, STEP = 2;
let sidePoints = [];

for (let x = -GX * STEP; x <= GX * STEP; x += STEP) {
    for (let y = 0; y <= GY * STEP; y += STEP) {
        sidePoints.push({ x, y });
    }
}
// Итого: (200/2 + 1) * (70/2 + 1) = 101 * 36 = 3,636 точек
```

### Кэширование

- **Генерация:** Один раз в `setup()`
- **Использование:** В `draw()` для каждой точки вызывается `calc()`
- **Оптимизация:** Не пересоздавать массив каждый кадр!

## 🦠 ОРГАНИЗМЫ

### Структура объекта

```javascript
organisms = [{
    x: 0.5,           // Позиция X (0-1, % экрана)
    y: 0.5,           // Позиция Y (0-1, % экрана)
    phase: 0.0,       // Фаза времени (сдвиг анимации)
    scale: 1.0,       // Индивидуальный масштаб
    rotation: 0.0,    // Угол вращения (радианы)
    targetX: 0.5,     // Целевая позиция (для притяжения к мыши)
    targetY: 0.5      // Целевая позиция Y
}];
```

### Позиции по умолчанию

```javascript
function initOrganisms() {
    organisms = [];
    for (let i = 0; i < orgCount; i++) {
        organisms.push({
            x: 0.5,
            y: 0.5,
            phase: i * 0.5,
            scale: 0.8 + i * 0.1,
            rotation: 0
        });
    }
}
```

### Взаимодействие с мышью

| Действие | Переменные | Логика |
|----------|------------|--------|
| **Перетаскивание (ЛКМ)** | `dragging`, `dragOrgIndex` | `mousePressed()` → поиск по радиусу 100px |
| **Вращение (ПКМ)** | `rotating`, `rotateOrgIndex` | `contextmenu` + движение по диагонали |
| **Притяжение** | `mouseAttraction` | `org.x += (mouseX - org.x) * mouseAttraction * 0.05` |

┌─────────────────────────────────────────────────────────┐
│ 1. draw() — начало кадра                                │

│    - showParticles → частицы                            │
