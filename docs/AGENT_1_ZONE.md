## 📐 Математическое ядро

### Функция `calc(x, y, time, scale)`

**Входные параметры:**
| Параметр | Тип | Описание |
|----------|-----|----------|
| `x` | number | Входная координата X (сетка) |
| `y` | number | Входная координата Y (сетка) |
| `time` | number | Время для анимации |
| `scale` | number | Масштабирование результата |

**Возвращаемое значение:**
```javascript
{ X: number, Y: number }  // Экраные координаты
```

---

## 🔢 Параметры формул

Объект `P` содержит глобальные параметры:

```javascript
let P = {
    k: 8,    // Делитель для k = x/8 - 12.5
    e: 24,   // Делитель для e = cos(k) + sin(y/24) + ...
    q: 90    // Добавка для q = x/4 + 90 + ...
};
```

### Влияние параметров

| Параметр | Диапазон | Влияние на форму |
|----------|----------|------------------|
| **k** | 2-20 | Определяет "ширину" организма |
| **e** | 5-50 | Влияет на частоту волн |
| **q** | 20-200 | Определяет "плотность" формы |

## 📊 Сетка координат

### Константы
```javascript
const GX = 50;      // Полуширина сетки (точек)
const GY = 35;      // Полувысота сетки (точек, только Y+)
const STEP = 4;     // Шаг между точками
```

### Генерация точек
```javascript
// Только Y >= 0 (одна сторона для зеркала)
for (let x = -GX * STEP; x <= GX * STEP; x += STEP) {
    for (let y = 0; y <= GY * STEP; y += STEP) {
        sidePoints.push({ x, y });
    }
}
```

**Итого точек:** ~4,500 (кэшируются в setup())

## 🕐 Time-анимации

### Глобальное время
```javascript
let t = 0;       // Накопленное время
let ts = 0.3;    // Скорость времени (0-1)
```

### Фаза организма
Каждый организм имеет индивидуальную фазу:
```javascript
phase: i * 0.5  // Чтобы организмы не синхронизировались
```

### Использование в формулах
```javascript
// В формуле q:
q = x/4 + P.q + d*k*(1 + cos(4*d - 2*time + y/72))
//                        ^^^^ время создаёт анимацию
```

## 🔧 Формулы (кратко)

Полная документация: [FORMULAS.md](./FORMULAS.md)

```
k = x/8 - 12.5
e = cos(k) + sin(y/24) + cos(k/2)
d = |e|
q = x/4 + 90 + d·k·(1 + cos(4d - 2t + y/72))
c = y·e/594 - t/8 + d/6
X = q·cos(c) + 200
Y = (q/2 + 99·cos(c/2))·sin(c) + 6e + 200
```
