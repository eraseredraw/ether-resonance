## 🔮 Система частиц

### Текущая реализация
```javascript
// В draw() — НЕОПТИМАЛЬНО
for (let p of sidePoints) {
    let pt = calc(p.x * scale, p.y * scale, time, 1);
    let alpha = map(p.y, 0, GY*STEP, 255, 30);  // ← Расчёт каждый кадр!
    let size = map(p.y, 0, GY*STEP, 2.5, 0.5);  // ← Расчёт каждый кадр!
    ellipse(...);
}
```

### Оптимизированная реализация (План)
```javascript
// В setup() — кэширование
let sidePointsWithProps = [];
for (let p of sidePoints) {
    sidePointsWithProps.push({
        x: p.x,
        y: p.y,
        alpha: map(p.y, 0, GY*STEP, 255, 30),  // ← Один раз!
        size: map(p.y, 0, GY*STEP, 2.5, 0.5)   // ← Один раз!
    });
}

// В draw() — только рендер
for (let p of sidePointsWithProps) {
    let pt = calc(p.x * scale, p.y * scale, time, 1);
    fill(255, p.alpha);
    ellipse(..., p.size, p.size);
}
```

### Прирост производительности
| Метрика | Было | Станет |
|---------|------|--------|
| Вычислений в кадр | ~9,000 | ~4,500 |
| FPS (средний) | 45-55 | 60 |
| Нагрузка CPU | Высокая | Средняя |

## ✨ Glow эффект

### Вариант А: CSS (быстро)
```css
canvas {
    filter: drop-shadow(0 0 15px rgba(255,255,255,0.5));
}
```

**Плюсы:**
- ✅ Одна строка CSS
- ✅ Работает сразу на всём canvas
- ✅ Нет нагрузки на JS

**Минусы:**
- ❌ Размытие по всему canvas
- ❌ Менее контролируемо

### Вариант Б: WebGL (красиво)
```javascript
// В p5.js WebGL режиме
function draw() {
    createCanvas(windowWidth, windowHeight, WEBGL);
    // Bloom shader...
}
```

**Плюсы:**
- ✅ Настоящий bloom эффект
- ✅ Полный контроль

**Минусы:**
- ❌ Сложнее реализация
- ❌ Может тормозить на слабых GPU

**Рекомендация:** Начать с CSS, потом опционально WebGL.

## 🎚️ Логика слайдеров

### Проблема
> "Когда тянешь вперёд — ничего не происходит, в начале — большие изменения"

### Решение: Нелинейные кривые

#### Было (линейно)
```javascript
P.k = parseInt(e.target.value);  // 2-20 линейно
```

#### Станет (логарифмически)
```javascript
// Для K (ширина)
let raw = parseInt(e.target.value);  // 0-100
P.k = 2 + Math.pow(raw / 100, 0.5) * 18;  // 2-20 нелинейно
```

#### Для разных параметров
| Параметр | Кривая | Формула |
|----------|--------|---------|
| **K** | √ (мягкий старт) | `2 + (raw/100)^0.5 * 18` |
| **E** | √ (мягкий старт) | `5 + (raw/100)^0.5 * 45` |
| **Q** | ^2 (резкий старт) | `20 + (raw/100)^2 * 180` |
| **Time** | Линейно | `raw / 100` |
| **Size** | Линейно | `raw` |
