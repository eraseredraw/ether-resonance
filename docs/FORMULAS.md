# 📐 FORMULAS — Документация уравнений

## 📋 Обзор

Проект использует **7 взаимосвязанных уравнений** для создания процедурных организмов.

---

## 🔢 Основные формулы

### 1. k = x / K - 12.5

**Описание:** Базовое преобразование X координаты.

**Параметры:**
| Параметр | Переменная | Диапазон | По умолчанию |
|----------|------------|----------|--------------|
| K | `P.k` | 2-20 | 8 |

**Влияние на форму:**
- Меньше K → более "сжатая" форма
- Больше K → более "широкая" форма

---

### 2. e = cos(k) + sin(y / E) + cos(k / 2)

**Описание:** Тригонометрическая комбинация с Y координатой.

**Параметры:**
| Параметр | Переменная | Диапазон | По умолчанию |
|----------|------------|----------|--------------|
| E | `P.e` | 5-50 | 24 |

**Влияние на форму:**
- Меньше E → более частые волны
- Больше E → более плавные волны

**Математика:**
```
e = cos(k) + sin(y/E) + cos(k/2)
         ↑           ↑          ↑
    зависит от   зависит от   половина k
       k           y
```

---

### 3. d = |e|

**Описание:** Абсолютное значение e (всегда положительное).

**Цель:** Устранение отрицательных значений для стабильности.

---

### 4. q = x / 4 + Q + d · k · (1 + cos(4d - 2t + y / 72))

**Описание:** Динамическая волна с временной зависимостью.

**Параметры:**
| Параметр | Переменная | Диапазон | По умолчанию |
|----------|------------|----------|--------------|
| Q | `P.q` | 20-200 | 90 |

**Временная зависимость:**
```
cos(4d - 2t + y/72)
           ↑
        время t создаёт анимацию
```

**Влияние на форму:**
- Меньше Q → более "плотная" форма
- Больше Q → более "разреженная" форма

---

### 5. c = y · e / 594 - t / 8 + d / 6

**Описание:** Временная эволюция с комплексной зависимостью.

**Временная зависимость:**
```
c = y·e/594 - t/8 + d/6
             ↑
         время t
```

**Влияние:**
- Скорость анимации: 1/8 = 0.125 за кадр

---

### 6. X = q · cos(c) + 200

**Описание:** Финальная X координата (с центрированием).

**Центрирование:**
```
+200 → смещение для центрирования формулы
```

---

### 7. Y = (q / 2 + 99 · cos(c / 2)) · sin(c) + 6e + 200

**Описание:** Финальная Y координата (с центрированием).

**Компоненты:**
```
Y = (q/2 + 99·cos(c/2)) · sin(c) + 6e + 200
     ↑                ↑         ↑      ↑
  половина q       косинус   6e    центр
                   половины c
```

## 🎛️ Параметры формул

### Сводная таблица

| Параметр | Переменная | Формула | Диапазон | Default | Влияние |
|----------|------------|---------|----------|---------|---------|
| **K** | `P.k` | k = x/**K** - 12.5 | 2-20 | 8 | Ширина формы |
| **E** | `P.e` | e = sin(y/**E**) | 5-50 | 24 | Частота волн |
| **Q** | `P.q` | q = x/4 + **Q** + ... | 20-200 | 90 | Плотность |

### Нелинейная логика (План)

Для равномерного изменения форм:

```javascript
// K: мягкий старт (√)
P.k = 2 + Math.pow(raw / 100, 0.5) * 18;

// E: мягкий старт (√)
P.e = 5 + Math.pow(raw / 100, 0.5) * 45;

// Q: резкий старт (^2)
P.q = 20 + Math.pow(raw / 100, 2) * 180;
```

## 🕐 Временная зависимость

### Где используется время (t)

| Формула | Зависимость | Скорость |
|---------|-------------|----------|
| **q** | `-2t` внутри cos | 2.0 |
| **c** | `-t/8` | 0.125 |

### Эффект времени
```
t увеличивается → формулы "эволюционируют"
                   ↓
        cos(4d - 2t + y/72) меняется
                   ↓
        q меняется → X,Y меняются
                   ↓
        Визуальная анимация организма
```

## 🔀 Альтернативные формулы (План)

### Формула B (вариант)
```
k = x/K - 10
e = sin(k) + cos(y/E) + sin(k/3)
d = |e|
q = x/3 + Q + d*k*cos(3d - t + y/50)
c = y*e/500 - t/10 + d/4
X = q*sin(c) + 200
Y = (q/3 + 80*sin(c/3))*cos(c) + 5e + 200
```

### Формула C (вариант)
```
k = x/K - 15
e = cos(k/2) * sin(y/E) + cos(k)
d = |e| + 1
q = x/5 + Q + d*k*(2 + sin(5d - 3t + y/100))
c = y*e/700 - t/6 + d/8
X = q*cos(c*2) + 200
Y = (q/4 + 120*cos(c/4))*sin(c*2) + 8e + 200
```

### Переключение формул
```javascript
let formulaPreset = 'A';  // 'A', 'B', 'C'

function calc(x, y, time, scale) {
    if (formulaPreset === 'A') {
        return calcFormulaA(x, y, time, scale);
    } else if (formulaPreset === 'B') {
        return calcFormulaB(x, y, time, scale);
    } else if (formulaPreset === 'C') {
        return calcFormulaC(x, y, time, scale);
    }
}
```
