# 📖 PROJECT OVERVIEW

## 🎯 Концепция

**Ether Resonance** — интерактивная визуализация тригонометрических организмов.

### Вдохновение
Проект создан на основе видео о процедурных организмах, созданных математическими формулами (не CGI).

### Философия
> Минимализм создаёт сложность. 7 простых уравнений порождают бесконечное разнообразие форм.
