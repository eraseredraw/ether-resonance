## [0.4.0] — 14.03.2026 — Горячие клавиши и Пресеты

### Добавлено (Агент 2)
- ✅ Горячие клавиши для слоёв (1-5)
  - `1` — toggle Particles + sync UI
  - `2` — toggle Lines + sync UI
  - `3` — toggle Tentacles + sync UI
  - `4` — toggle Core + sync UI
  - `5` — toggle Glow + sync UI
- ✅ Горячие клавиши для действий
  - `F` — fullscreen (toggle)
  - `R` — reset rotation
  - `Space` — случайная формула (0-7)
- ✅ Пресеты (localStorage, 3 слота)
  - `savePreset(slot)` — сохранение всех параметров
  - `loadPreset(slot)` — загрузка + обновление UI
  - `clearPreset(slot)` — удаление пресета
  - Визуальная обратная связь при сохранении
- ✅ Функция `toggleFullscreen()`
- ✅ Тоггл "Glow" в layer-config панели
- ✅ Обработчик для `toggle-glow`

### Сохраняемые параметры в пресетах
- `P = {k, e, q}` — параметры формул
- `formulaVariant` — текущая формула (0-7)
- `particleColorMode` — цветовой режим
- `hueOffset` — смещение оттенка
- `showGlow` — состояние свечения
- `baseSize, orgCount, particleDensity, orgSize` — размеры
- `mouseAttraction` — притяжение к мыши

### Изменено
- 🔄 Обновлена панель управления — добавлена секция "💾 Presets"
- 🔄 Обновлена layer-config — добавлен тоггл Glow
- 🔄 Обновлены keyboard events — полный обработчик

### Технические детали
- localStorage для хранения пресетов
- Fullscreen API для полноэкранного режима
- Визуальная обратная связь (кнопка зеленеет на 1 сек)
